# 推し遷移

推しの移り変わりを年表にして、画像で共有できるスマホ向けWebアプリです。

**アプリを開く → https://kyo-dev-lab.github.io/oshi-seni/**

iPhoneはSafariで開いて「共有 → ホーム画面に追加」、AndroidはChromeのメニューから「ホーム画面に追加」すると、アプリのように使えます。

## できること

- 推しの登録（名前・推し始めた日・ジャンル・画像・ひとこと）
  - 日付は作成した日が最初から入り、あとから変更できます
  - ジャンルは「漫画・アニメ・カプ」に加えて自由に追加できます
  - 画像はトリミング（正方形・横長・縦長・なし）してから登録できます
- 3つの表示：縦の年表／横の年表／ジャンル別、ジャンルでの絞り込み
- カードをタップすると、推し始めてからの日数つきの詳細カードを表示
- 画像の書き出し：年表まるごと、インスタ投稿（1:1）、ストーリー（9:16）、X（16:9）
  - SNSサイズは数件ずつ複数枚に分けて作成し、スマホの共有メニューからまとめて送れます
- テーマカラー・フォント・文字サイズの変更（年表と画像の色も連動）
- データのバックアップ（書き出し・読み込み）
- 初回起動時のチュートリアル

## データの保存について

データはすべて、開いた端末のブラウザの中（localStorage）に保存されます。サーバーには送られません。
機種変更やブラウザのデータ削除に備えて、設定画面の「データのバックアップ」から書き出しておくのがおすすめです。

## 技術

- HTML / CSS / JavaScript（フレームワーク・ビルドなし、`index.html` 1ファイル）
- 画像の生成は Canvas API、共有は Web Share API
- フォント：Google Fonts（M PLUS Rounded 1c ほか）
